Ringkasan cepat proyek Admin Panel & Membership System (AJSHOP). Dokumen ini dibuat otomatis dan tersedia di repository.

Ringkasan Singkat

PANEL AJSHOP adalah sebuah aplikasi web administrasi modern yang dibuat dengan Python (Flask) dan SQLite. Menyediakan fitur authentication, manajemen user & member, manajemen produk, serta dashboard analytics.

Teknologi

  • Backend: Python 3 + Flask
  • Database: SQLite (file ajshop.db)
  • Frontend: HTML5, CSS, Bootstrap 5, Vanilla JavaScript
  • Auth: JWT (Flask-JWT-Extended)
  • Dependencies: lihat requirements.txt

Fitur Utama

  • Login / Register dengan JWT dan password hashing
  • Role-based access: admin, moderator, member, user
  • Manajemen Users (CRUD)
  • Manajemen Members (membership type, status, points)
  • Manajemen Products (CRUD, stock, category)
  • Dashboard: statistik realtime & recent activities
  • Activity logging (login, logout, actions)

Instruksi Singkat Menjalankan Aplikasi

  1. Clone repository: git clone https://github.com/anandaanandaresoa-commits/Ajishop.oi.git
  2. Buat virtualenv dan aktifkan: python -m venv venv & source venv/bin/activate
  3. Install dependency: pip install -r requirements.txt
  4. Inisialisasi database: python init_db.py
  5. Jalankan server: python app.py — akses di http://localhost:5000
